# Zerodha Clone

A responsive Zerodha-inspired trading dashboard built using HTML, CSS, and JavaScript.

## 🚀 Features

* 🔐 Login interface
* 📊 Trading dashboard
* 📈 Interactive stock chart
* 🔎 Stock search
* 👀 Stock watchlist
* 🟢 Buy and Sell interface
* 💼 Portfolio management
* 💰 Dynamic Profit & Loss calculation
* 📋 Recent orders
* 🌙 Dark mode
* 📱 Responsive design
* 🔔 Order confirmation notifications
* 📊 Simulated market price updates

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Chart.js
* Font Awesome
* Git
* GitHub

## 💻 How to Run

Clone the repository:

```bash
git clone https://github.com/artitotawar45/zerodha.git
```

Open the project folder and launch `index.html` in your browser.

For development, you can use the Live Server extension in VS Code.

## 📊 Project Overview

This project is a frontend trading dashboard inspired by modern stock trading platforms.

Users can view market information, search stocks, manage a watchlist, place simulated Buy/Sell orders, monitor their portfolio, and view dynamically calculated Profit & Loss.

## ⚠️ Disclaimer

This project is created for educational and portfolio purposes only.

It does not connect to Zerodha's trading infrastructure and does not execute real stock market transactions. All prices, portfolio values, and orders are simulated.
